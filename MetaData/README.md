# 📊 Telegram Metadata Extractor Bot

Бот для извлечения метаданных из файлов в Telegram.

## ✨ Возможности

- 🖼️ Извлечение EXIF данных из изображений
- 📍 GPS координаты с ссылкой на Google Maps
- 🎵 Метаданные аудиофайлов (ID3, Vorbis)
- 🎬 Информация о видеофайлах
- 📄 Метаданные PDF документов
- 📊 Общая информация о файлах
- 🎨 Красивое форматирование вывода
